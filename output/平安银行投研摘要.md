## Model / Data Checks（数据核对与修正）

- 数据源：东方财富 F10（银行专项指标：净息差 / 不良率 / 拨备 / 资本充足）+ 同花顺 / 新浪财报 + 腾讯行情；

  +3.32%，两源一致；
- **修正①**：每股净资产采用「调整后（归母普通股）」口径 **24.13 元**（2026H1）——此前误用调整前
  28.25 元；按 24.13 元计算 PB≈0.46，与行情口径吻合；
- **修正②**：归母净利采用 **256.96 亿**（东财口径）；此前引用的 256.33 亿为扣非口径，两者同比均为 +3.32%；
- 局限：净息差 / 不良率 / 拨备数据来自东方财富 F10，正式引用前建议以半年报原文复核；
  本次未做同业对比与 DCF / PB-ROE 情景建模。

## Risks and Counterarguments（风险与反方观点）

1. 营收连续两年负增长（2024 -10.9%、2025 -10.4%），净利转正可能依赖拨备释放与费用压降，持续性待验证；
2. 净息差绝对值仍处低位（1.80%），若重定价压力再起将侵蚀盈利；
3. 房地产与零售信贷敞口的资产质量尾部风险；
4. 反方观点：低 PB 可能是「价值陷阱」，估值修复依赖 ROE 企稳与分红提升；
5. 技术面矛盾：MACD 空头 + 均线缠绕，双均线策略近期跑输基准（-3.67% vs +5.21%）。
